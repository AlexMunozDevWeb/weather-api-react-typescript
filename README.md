* API - Interfaz de programación de aplicaciones
* Funciones, métodos que ofrece una librería para ser utilizada por otro software como una capa de abstracción.
* Una API pona a disposición recursos que están alojados en otro servidor o base de datos.
* Utilizando React en el ciente con Vite, no puede consultar una base de datos, por lo tanto consultar una API es una forma de obtener datos dinámicos de un servidor o base de datos.
* La API puede ser creada en cualquier lenguaje o framework: Python, Java, Net Core, Express, Node.js, Laravel, PHP.
* Normalmente una API da una respuesta de tipo JSON.
* Algunas estan protegidas por keys y otras por CORS.
